# 🟡 Maze Muncher

**Maze Muncher** is a browser-based, retro-inspired arcade maze chase game built with **HTML, CSS, and vanilla JavaScript**. Collect dots, grab power orbs, avoid the ghosts, and aim for a new high score.

> This is an original fan-inspired project. It is not affiliated with or endorsed by the owners of Pac-Man. The game uses its own name and implementation.

![Maze Muncher game thumbnail](thumbnail.png)

## 🎮 Features

- **Classic maze-chase gameplay** with a player, corridors, walls, dots, and power orbs.
- **Keyboard controls** using the arrow keys or WASD.
- **Ghost opponents** with basic chase and scatter behavior.
- **Power-up mode** that temporarily lets the player catch ghosts for bonus points.
- **Scoring and lives**, with three lives to start.
- **Bonus fruit** that appears at score milestones for extra points.
- **Multiple levels** with increased ghost speed as you progress.
- **Sound effects** with an in-game sound toggle.
- **Pause and restart controls**.
- **High-score saving** in the browser when local storage is available.
- **Responsive layout** and on-screen directional controls on touch-enabled devices.

## 🕹️ Controls

| Action | Controls |
|---|---|
| Move | `↑` `↓` `←` `→` or `W` `A` `S` `D` |
| Pause / resume | `Space` or the Pause button |
| Start / continue | `Enter` or the on-screen button |
| Restart | Restart button |
| Toggle sound | Sound button |

## 🚀 Play locally

1. Download or clone this repository.
2. Keep the HTML file named `index.html` (recommended for static hosting).
3. Double-click `index.html` to open it in a modern browser such as Microsoft Edge or Google Chrome.
4. Click **Start game** and play.

No Node.js, package installation, or build step is required for the standalone HTML version.

## ☁️ Deploy to Vercel

1. Create a GitHub repository and upload `index.html` and this `README.md`.
2. If you want the thumbnail to appear in this README, also upload the image as `thumbnail.png` in the repository root.
3. In Vercel, import the GitHub repository.
4. Use the default project settings for a static site. No build command is needed.
5. Deploy. Vercel will serve `index.html` as the site homepage.

If your downloaded file is currently named `maze_muncher_phase2.html`, rename it to **`index.html`** before uploading.
